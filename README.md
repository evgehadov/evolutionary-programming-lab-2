# Лабораторная работа № 2
## Генетический алгоритм для задачи закупки расходных материалов

**Дисциплина:** Эволюционное программирование
**Вариант:** № 6
**Язык:** Python

## 1. Описание задачи

Необходимо составить месячный план закупки расходных материалов с учётом бюджета и минимальных запасов.

Для каждого материала заданы:
- идентификатор и название;
- цена единицы;
- текущий запас;
- ожидаемый спрос;
- минимальный остаток;
- вес полезности;
- ограничение на дополнительный запас.

Генотип представляет собой целочисленный вектор \(x\), где \(x_i\) — количество закупаемых единиц материала \(i\).

Алгоритм должен максимизировать суммарную полезность плана при соблюдении бюджетного ограничения и допустимых границ закупки.

## 2. Структура проекта

- `main.py` — точка входа в программу.
- `procurement_ga/` — основной пакет проекта:
  - `models.py` — модели данных и конфигурации;
  - `data_generator.py` — генерация исходных данных;
  - `objective.py` — целевая функция и расчёт полезности;
  - `constraints.py` — проверка ограничений, штрафы и восстановление допустимых решений;
  - `operators.py` — генетические операторы;
  - `genetic_algorithm.py` — реализация генетического алгоритма;
  - `baseline.py` — жадная эвристика для сравнения;
  - `experiments.py` — экспериментальные конфигурации и серии запусков;
  - `reporting.py` — сохранение результатов;
  - `cli.py` — интерфейс командной строки.

## 3. Установка

Рекомендуется использовать виртуальное окружение.

Создание и активация окружения на macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install numpy matplotlib
```

## 4. Запуск

Все команды выполняются из корневой директории проекта.

Посмотреть справку:

```bash
python main.py --help
```

Проверить исходные данные:

```bash
python main.py check-data
```

Посмотреть примеры допустимых и недопустимых планов:

```bash
python main.py demo
```

Проверить генетические операторы:

```bash
python main.py check-operators
```

Выполнить один запуск генетического алгоритма:

```bash
python main.py run-ga
```

Запустить одну экспериментальную конфигурацию:

```bash
python main.py run-experiment A
```

Сравнить экспериментальные конфигурации A–D с жадной эвристикой без сохранения файлов:

```bash
python main.py compare
```

Выполнить полную серию экспериментов и сохранить результаты:

```bash
python main.py run-all
```

## 5. Экспериментальные конфигурации

Реализованы четыре конфигурации, позволяющие сравнить стратегии обработки ограничений и варианты мутации:

| Конфигурация | Обработка ограничений | Мутация |
|---|---|---|
| A | Восстановление допустимого решения (`repair`) | Пошаговая (`step`) |
| B | Восстановление допустимого решения (`repair`) | Переназначение значения (`reassign`) |
| C | Штрафная функция (`penalty`) | Пошаговая (`step`) |
| D | Штрафная функция (`penalty`) | Переназначение значения (`reassign`) |

Результаты генетического алгоритма сравниваются с результатом жадной эвристики.

## 6. Результаты

Команда `run-all` сохраняет результаты в директорию `results/`. В неё входят таблицы с исходными данными, параметрами экспериментов, результатами отдельных запусков и сводной статистикой, а также графики сравнения конфигураций и жадной эвристики.

Содержимое и названия выходных файлов определяются реализацией модуля `reporting.py`.
